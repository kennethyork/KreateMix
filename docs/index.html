Your own social media scheduler,

KreateMix schedules posts, tracks analytics and answers comments across 11 networks. It's a single index.php, so you can run it yourself and keep your data and your accounts' tokens on your own server.

Composer and calendar

One post to many accounts with per-network text, live previews, stories, first comments, and a month and week calendar.

Autolists and CSV import

Evergreen queues that post on a schedule, and bulk scheduling from a spreadsheet.

Analytics and reports

Followers, engagement and top posts, a best-time-to-post heatmap, and white-label PDF and PowerPoint reports.

Inbox

Comments from seven networks in one place, with replies sent from KreateMix.

What it costs to run

KreateMix itself is free. You pay for a small server and a domain name.

Server (VPS)

$2/month to start

A 2 GB VPS from IONOS is $2 a month for the first 3 months. For the lowest long-term price, RackNerd's 2 GB plan is about $3 a month, billed yearly. Compare them.

Domain name

~$10/year

Needed for HTTPS and for connecting social accounts. A subdomain of one you already own works too, at no extra cost.

Control panel

$0

CloudPanel is free. It gives you a web dashboard for the site, PHP settings, free HTTPS certificates, cron jobs and backups, so you don't have to manage the server by hand.

How setup works

The full guide walks through every click and command.

  1. Rent a 2 GB VPS running Ubuntu 24.04 and point your domain at it.
  2. Install CloudPanel with one command.
  3. Create a PHP site in CloudPanel and turn on free HTTPS.
  4. Download index.php into the site and open your domain to create your admin account.
  5. Add one cron job so scheduled posts go out on time.
  6. Add API keys for the networks you use. Mastodon, Pixelfed, PeerTube and Bluesky need none.
